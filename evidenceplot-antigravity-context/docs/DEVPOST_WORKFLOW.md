## Official skill-pack contract
Install in an empty new project workspace:
```bash
npx skills add challengepost/learn-ai-basics --all -y
```
Official pack: https://github.com/challengepost/learn-ai-basics

Skill sequence:
1. `1-start`: learner profile (`devpost/learner-profile.md`), typically ignored by Git.
2. `2-scope`: user-led scope interview → `devpost/scope.md`.
3. `3-prd`: user-led product interview → `devpost/prd.md`.
4. `4-spec`: technical choices agreed → `devpost/spec.md`.
5. `5-build`: tracked verified builds → `devpost/checklist.md`, app and `devpost/app-map.html`.
6. `6-ship`: public demo, repository and learner-authored submission text.

**Frontmatter statuses:** draft → approved only on explicit learner approval. Do not skip interviews, manufacture approvals, pre-create mandatory files outside skills, or treat this context pack as satisfying official planning requirements. Skills may change: follow installed current instructions as highest priority.

## Required hackathon deliverables (official rules)
- New original software project made during submission period, end-to-end function actually working.
- Public functional source repository with necessary assets and instructions, plus visible open-source license.
- Skill-pack-generated `devpost/scope.md`, `devpost/prd.md`, `devpost/spec.md` included in repository.
- Public video **under 3 minutes** on YouTube/Vimeo showing real application on its intended device.
- Accurate public text description, demo/app URL when relevant, required Devpost form responses, and repository URL.
- Disclose incorporated pre-existing code/work other than standard framework/library scaffolding as required.
- User must register and check all age/territory and prize eligibility rules personally.

## Judging dimensions (equally weighted)
1. Design — coherent finished experience.
2. Potential impact — real user, real problem, evidence of useful result.
3. Innovation — meaningful distinction from existing tools.
4. Presentation — convincing live end-to-end demo.

## Proposed 2:40 demo
- 0:00–0:20: Researcher's problem: plots can be inconsistent/unverifiable.
- 0:20–0:40: Upload fully synthetic CSV; show data quality profile.
- 0:40–1:05: Type analysis goal; AI suggests allowlisted plan; confirm assumptions.
- 1:05–1:35: Python returns calculation; render figure with raw points and actual numeric results.
- 1:35–2:00: Edit title/units/style; show caution about interpretation.
- 2:00–2:25: Export verified chart and Passport; show file contents.
- 2:25–2:40: Impact and reproducibility story, URL.

## Critical warning
**Do not treat a synthetic statistical significance result as evidence of a scientific discovery.** Demo must be accurate, clearly synthetic and reproducible. Do not show invented analysis outcomes.
